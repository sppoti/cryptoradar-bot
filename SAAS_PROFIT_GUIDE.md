## 2. Технический запуск за 60 секунд (1-Click Quickstart)

В проект заложена одновременная работа Telegram-бота и высокоскоростного Web API сервера Mini App в едином асинхронном цикле (`bot.py` + `web_server.py`).

```
                    ┌───────────────────────────────┐
                    │       КЛИК ПО run.bat         │
                    └──────────────┬────────────────┘
                                   │
                    ┌──────────────▼────────────────┐
                    │     Запуск Python 3.14        │
                    ├───────────────────────────────┤
                    │ • Инициализация SQLite DB     │
                    │ • Запуск aiohttp на порту 8080 │
                    │ • Запуск Aiogram Long-Polling │
                    │ • Фоновый автопилот аналитики │
                    └───────────────────────────────┘
```

### Шаг 2.1. Конфигурация файла `.env`
Откройте файл `c:\TG\.env` (или создайте его из `.env.example`) и заполните основные поля:

```env

# 2. Ваш числовой ID в Telegram (узнать в @userinfobot)
ADMIN_ID=543219876

# 3. Название вашего проекта (отображается в меню и чеках)
PROJECT_NAME=CryptoRadar & VIP Insider

# 4. Ссылка на закрытый канал/чат, выдаваемая после успешной оплаты
VIP_LINK=https://t.me/+AbCdEfGhIjK12345

# 5. Канал для автопостинга сводок (опционально: -100... или @channel)
CHANNEL_ID=@my_crypto_radar_channel
AUTOPILOT_INTERVAL_HOURS=4

# 6. Реквизиты для оплаты через СБП / Карту (видят клиенты)
MANUAL_PAYMENT_DETAILS="💳 Оплата по СБП / Карте:\nБанк: Т-Банк / Сбер\nНомер телефона (СБП): +79991234567\nПолучатель: Иван И."

# 7. Адрес для WebApp (для локального теста или туннеля)

WEB_HOST=0.0.0.0
WEB_PORT=8080
```

### Шаг 2.2. Запуск в 1 клик
Дважды щелкните по файлу `run.bat` в папке проекта.
Консоль выдаст подтверждение:
```text

====================================================
2026-11-16 22:00:00 - INFO - TGBot - Инициализация базы данных SQLite...
2026-11-16 22:00:01 - INFO - aiohttp.access - Web-сервер запущен на http://0.0.0.0:8080

🌐 TMA WebApp: http://0.0.0.0:8080

```

### Шаг 2.3. Публичный доступ к WebApp (HTTPS)
Telegram требует **HTTPS** для открытия WebApp внутри мессенджера. 
Для бесплатного продакшен-запуска используйте **Cloudflare Tunnel** (надежнее и стабильнее ngrok):

1. Скачайте бесплатную утилиту [Cloudflared](https://github.com/cloudflare/cloudflared/releases) (один exe-файл).
2. Запустите в терминале:
   ```powershell
   cloudflared tunnel --url http://127.0.0.1:8080
   ```
3. Cloudflare выдаст красивый бесплатный HTTPS-адрес: `https://something-random.trycloudflare.com`.
4. Вставьте этот адрес в `WEBAPP_URL=` в вашем файле `.env` и перезапустите `run.bat`.

## 3. Настройка Telegram Stars (⭐) через @BotFather (0 юридических хлопот)

**Telegram Stars** — это официальная цифровая валюта Telegram. Клиенты покупают Звезды в 1 тап через банковские карты, Apple Pay или баланс App Store / Google Play.

> [!NOTE]
> **Главное преимущество:** вам не нужно открывать ИП, регистрировать кассу или подключать эквайринг. Telegram сам удерживает налог платформы и начисляет Stars на баланс вашего бота.

### Пошаговая инструкция настройки:
1. Откройте диалог с официальным ботом [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/mybots` и выберите вашего бота из списка.
3. Нажмите кнопку **Bot Settings** → **Payments**.
4. В списке провайдеров выберите **Telegram Stars** (или `Digital Goods / Stars`).
5. Нажмите **Connect Telegram Stars**. Бот автоматически активирует поддержку платежей Stars!

### Как выводятся деньги:
- Все заработанные Stars отображаются в профиле вашего бота в разделе **Balance** в BotFather.
- Спустя 21 день после платежа Звезды становятся доступны к выводу через официальную децентрализованную платформу **[Fragment.com](https://fragment.com)**.
- Привяжите ваш кошелек **Tonkeeper** или **Telegram Wallet**.
- В 1 клик переведите Stars в криптовалюту **TON** или стейблкоин **USDT**.
- Через P2P-маркет в Telegram Wallet продайте TON/USDT за рубли на карту любого банка (Сбер, Т-Банк, Райффайзен) без комиссий за 3 минуты.
